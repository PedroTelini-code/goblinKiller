🧙‍♂️ Goblin Slayer - Construct 3 Game
Goblin Slayer é um jogo de ação desenvolvido na plataforma Construct 3, onde você assume o papel de um poderoso mago em uma masmorra infestada de goblins. Seu objetivo é derrotar o maior número possível de inimigos, acumulando pontos e desafiando seus próprios recordes!

🔥 Jogue aqui:   🔥

🎮 Sobre o Jogo
Você é um mago solitário em uma masmorra obscura. Armado apenas com sua magia, deve sobreviver a ondas de goblins que surgem sem parar. Cada goblin derrotado aumenta sua pontuação — quanto mais sobreviver, mais alto será seu placar!

🛠️ Tecnologias Utilizadas
Construct 3 – Engine de desenvolvimento principal

HTML5 – Plataforma de exportação

Sprites 2D – Gráficos e animações

🚀 Como Jogar
Movimentação: Use as teclas direcionais para mover o mago.

Ataque: clique para lançar magia.

Objetivo: Derrote o máximo de goblins possível para aumentar sua pontuação.
